## Featured Projects

### Financial Data Lakehouse

[View Repository](https://github.com/Nishant1242/financial-data-lakehouse)

Built a containerized data lakehouse platform for ingesting, transforming, validating, and analyzing cryptocurrency market data.

**Technology:** Kafka, PySpark, MinIO, PostgreSQL, MongoDB, dbt, Airflow, Docker, and Streamlit

**Key capabilities:**

- Streams cryptocurrency market data through Kafka
- Implements Bronze, Silver, and Gold data layers
- Applies schema validation, deduplication, and data-quality rules
- Builds analytics models using dbt and PostgreSQL
- Orchestrates pipeline tasks using Apache Airflow
- Presents business metrics through an interactive Streamlit application

---

### Flightlog Summarizer

[View Repository](https://github.com/Nishant1242/flightlog-summarizer)

Built an NLP application that summarizes aviation maintenance logs and reduces the time required to review lengthy technical records.

**Technology:** Python, BART, Transformers, Streamlit, and ROUGE

**Key capabilities:**

- Preprocesses unstructured aviation maintenance text
- Generates concise maintenance-log summaries
- Evaluates summary quality using ROUGE metrics
- Provides an interactive interface for entering and reviewing logs
